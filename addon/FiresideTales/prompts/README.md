# Adding stories with AI

Fireside Tales comes with starter stories. To add more:

1. Pick a prompt from this folder, copy it into an AI, and fill in the bracketed parts.
2. In the game, click the book icon on the minimap, then **Write My Story**, or type `/tales add`.
3. Paste what the AI wrote and press **Add**. A few stories at a time works best.

The stories appear in your menu right away. **Write My Story** tells you how many it added, and why it skipped any. Read them before you tell them, since you're the one saying them out loud.

| Prompt | What it writes |
| --- | --- |
| `character-stories.md` | Stories only one character tells, from their own life |
| `race-and-class-stories.md` | Stories for any character of a race or class |
| `zone-stories.md` | Tales of a place, which rise to the top when you're there |
| `stories-for-everyone.md` | Stories any character can tell, grouped by theme |
| `stories-told-to-someone.md` | Stories told to one listener by name |

Pasted stories are saved for your whole account, with each one showing only on the characters it fits. They're kept outside the addon's folder, so updating the addon doesn't remove them. Adding a story with the same title to the same list replaces the old one, and **Delete** in the menu removes one.
